### P0-2 预备方案（已备好，盘点回报后即可执行）
> 已落盘一键脚本：`setup_env.sh`（拷到 Ubuntu 执行，自动装基础工具 + 建目录 + 交叉编译链三选一）。

1. **基础工具**（手册 2.1）：
   ```bash
   sudo apt update && sudo apt install -y \
       build-essential git vim curl wget \
       minicom picocom net-tools \
       nfs-kernel-server tftp-hpa \
       libncurses5-dev libssl-dev \
       bison flex bc u-boot-tools \
       pkg-config libtool autoconf automake \
       python3 python3-pip python3-venv \
       ssh openssh-server
   ```
2. **开发目录**（手册 2.1）：
   ```bash
   mkdir -p ~/imx6ull/{edge-ai-gateway,imx6ull-drivers,buildroot,linux-imx6ull,rootfs}
   ```
3. **交叉编译链**（手册 2.2 方案 A）：
   - 正点原子资料光盘 `gcc-linaro-4.9.4-2017.01-x86_64_arm-linux-gnueabihf.tar.xz` → 解压到 /opt
   - 或 `apt install gcc-arm-linux-gnueabihf`（较新 glibc，编译老内核 4.9.88 可能需注意兼容性，推荐用光盘 4.9.3）
   - 环境变量写入 ~/.bashrc
4. **内核源码**（手册 2.3）：正点原子 Gitee `https://gitee.com/GuangzhouXingyi/ebf_linux_kernel.git` 或资料光盘 kernel 源码

### P0-3 预备方案（内核源码获取与编译，手册 2.3）
```bash
# 源码获取（任选）：
#   Gitee: git clone https://gitee.com/GuangzhouXingyi/ebf_linux_kernel.git linux-imx6ull
#   或资料光盘 kernel 源码拷贝到 ~/imx6ull/linux-imx6ull

cd ~/imx6ull/linux-imx6ull
export ARCH=arm
export CROSS_COMPILE=arm-linux-gnueabihf-
make imx6ull_alientek_emmc_defconfig    # 正点原子 EMMC 版默认配置
# 若目标不存在：make menuconfig 手动配置
make -j$(nproc)
# 产物：arch/arm/boot/zImage + arch/arm/boot/dts/imx6ull-14x14-emmc.dtb
# 验证可编模块：ls include/generated/autoconf.h（不存在则补：make defconfig && make prepare scripts）
```
> 注意：内核源码树是项目 B 驱动模块编译的 KDIR 目标（手册 2.3 末尾）。

### P0-4 预备方案（串口连通 + 网络配置，手册 2.4）
```bash
# 串口（USB 转串口，一般 /dev/ttyUSB0）
sudo minicom -D /dev/ttyUSB0 -b 115200    # 或 sudo picocom -b 115200 /dev/ttyUSB0
# 板子启动应看到 U-Boot 与内核日志，最终到 shell 提示符

# 网络（板子与 PC 同一网段）
# PC 端：sudo ip addr add 192.168.1.100/24 dev eth0
# 板端（串口里）：ifconfig eth0 192.168.1.101 netmask 255.255.255.0
# 验证：ping 192.168.1.100（板端 ping PC）
```

### P0-5 预备方案（NFS/TFTP 开发模式，手册 2.5）
```bash
# PC 端配置 NFS
echo "/home/$USER/imx6ull/rootfs *(rw,sync,no_root_squash,no_subtree_check)" | sudo tee -a /etc/exports
sudo exportfs -ra
# 把正点原子出厂 rootfs 解压到 ~/imx6ull/rootfs

# 板端 U-Boot 改 bootargs 为 nfsroot 方式（串口里）
# setenv bootargs 'console=ttymxc0,115200 root=/dev/nfs nfsroot=192.168.1.100:/home/xxx/imx6ull/rootfs rw ip=192.168.1.101::192.168.1.1:255.255.255.0::eth0:off'
```
> 开发期常用：U-Boot 网络引导内核（TFTP）+ NFS rootfs，应用改动直接复制即生效，无需反复烧写。

### P0-6 预备方案（Buildroot 最小系统，手册 2.6）
```bash
cd ~/imx6ull
git clone https://github.com/buildroot/buildroot.git
cd buildroot
make qemu_arm_vexpress_defconfig    # 先用模拟器配置练手（或直接配 imx6ull）
make menuconfig                     # Target options: ARM Cortex-A7 / EABIhf
make -j$(nproc)                     # 首次约 30-60 分钟
# 产物：output/images/rootfs.ext2 zImage
```
> P0 只需"构建出能启动的最小系统"；完整板级配置在 P6 细化（手册 4.14）。
